# Ninja Notes   

Ninja Notes is a web application designed for university students to access and organize class notes, previous year papers, and educational blogs. Students can also sign up, log in, and save their notes for easy access in the future, reducing the need to search repeatedly.

## Demo

https://ninjanotesorg.vercel.app/

## Features

- **Class Notes** : University notes for different subjects and departments.
- **Previous Year Papers** : Access to previous exam papers for exam preparation.
- **Blogs** : Educational blogs to provide extra knowledge and tips.
- **Login/Signup** : Users can create accounts, log in, and personalize their experience.
- **Save Notes** : Logged-in users can save notes for easy access in the future.
- **Search and Filter** : Users can search and filter resources by subjects, departments, or keywords.
- **User-friendly Interface** : A clean, responsive UI for easy navigation.

- ## Tech Stack

**Client:** React, Redux, TailwindCSS
**Server:** Node, Express
**Database:** MongoDB
**Authentication:** JWT
**File Storage** Cloudinary

## Run Locally

Clone the project

```bash
  git clone https://github.com/kbhavre/NinjaNotes.git
```

Go to the project directory

```bash
  cd my-project
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start
```
